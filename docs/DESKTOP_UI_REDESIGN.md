# Desktop 界面改版 v0.1.1（2026-10-27）

主界面改为以交流为中心：左侧话题列表、顶部 A/B 智能体卡片、中部独立滚动时间线、底部固定输入框。A/B 和用户消息有不同头像、对齐和配色，关联编号按需展开。创建话题、连接设置、预算详情、诊断维护改为独立弹窗；窄屏有话题选择器及创建/管理图标。消息保持纯文本。

交互增加 Ctrl+Enter 发送、Escape 关闭弹窗、Tab 焦点循环与关闭后的焦点恢复。请求未确认、拒绝及维护结果继续显式展示；待确认请求使用原实例和原幂等键。既有发送、预算、维护调用以及官方 main/sidebar/settings 插槽保持原契约。

## 验证

可复现命令：

```powershell
npm run desktop:build
npm run test:native:ui
npm run test:desktop-native
npm run check
```

- 原生 Chromium 组件测试通过：真实组件/Host 桥接与临时数据库，模型 Runtime 使用模拟实现。覆盖 A/B 定向发送、响应丢失/重开/跨实例拒绝/原键重试、脚本正文、暂停恢复结束、历史分页与轮询、只读诊断及 390px 窄屏；增加弹窗焦点循环、Escape、Ctrl+Enter 和窄屏管理入口检查。
- 9 项插件/进程回归、TypeScript 检查通过。
- 1100×950 与 390×844 浏览器截图人工检查通过。测试截图可通过设置 `DMN_UI_SHOTS=1` 保存；这些为模拟数据，不是模型验收证据。
- 本机 DSH Desktop 0.2.1-rc.3 实际打开新版主面板，检查双节点、空状态、底部输入框、新建话题弹窗与 Escape 关闭。打开和关闭弹窗没有提交话题或输入，也没有发起真实计费模型调用。真实模型能力沿用 N5 历史验收，不将本轮视觉检查表述为新增模型端到端验收。

## 契约、迁移和限制

仅更改客户端展示、浏览器回归和文档，插件版本升为 0.1.1。无数据库 Schema、Host/管道协议、预算、授权或节点能力变更，无需数据迁移。原有实例、根会话和私有记忆继续使用原路径。本机通过已安装的源码链接加载构建结果。

本轮实际 Desktop 检查为常规窗口；窄屏交互在 Chromium 模拟宿主中验证。仍仅支持现有 Windows rc3 与双节点，不增加第三节点、跨 Provider 或 P6 能力。
