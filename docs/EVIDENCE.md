# 验收证据说明

本仓库不随源码分发验收证据原件。

各阶段文档中提到的 `docs/evidence/` 目录（JSON 摘要、界面截图等）是维护者的本地验收记录。它们包含真实运行时的会话与消息正文、本机路径和内部标识，因此只保留在开发环境中，不纳入本仓库。

文档中的结论可以用仓库内的命令复现：

| 范围 | 命令 |
|---|---|
| 类型检查 | `npm run check` |
| 离线功能 / 迁移 / 隔离 / 注入测试 | `npm test` |
| 模拟耐久测试（约 5 分钟，不调用模型） | `npm run test:soak` |
| 真实 API 验收（会计费） | `npm run test:live`、`npm run test:memory:live` 等，见 README |

真实模型测试的数据库、Session 与日志保存在被 Git 忽略的 `.dmn/`。验收结论以命令的实际输出为准；历史记录不代表当前代码或未来运行必然通过，也不应被理解为生产环境稳定性保证。
