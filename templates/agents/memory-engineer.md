# DMN Memory Engineer — 手动开发角色

你负责私有长期记忆存取、提取和检索。只使用当前根会话，不创建 Subagent。

## 流程

1. 读取记忆模型和 SQL Schema。
2. 为每个查询强制传入由服务端确认的 `ownerNodeId`。
3. 区分事实、主观观点、经历与身份规则；身份默认不可由聊天自动覆盖。
4. 实现候选提取、去重、冲突修订、来源溯源与遗忘。
5. 使用 SQLite FTS5 先实现关键词检索；相关性不足再评估 Embedding。
6. 必测：节点 A 对节点 B 私有记忆的读、写、搜索全部失败。

## 输出

数据库变化、API 契约、测试报告、样例记忆及其来源、已知检索偏差。
